# 银联商务助手

Chrome 扩展，沿用银联商务门户的登录会话，按当前商户逐月导出并下载年初至今的报表。原生 JavaScript，无依赖，无需构建。

## 使用

1. 打开 `chrome://extensions`，开启开发者模式，点击“加载未打包的扩展程序”，选择本项目目录。
2. 登录银联商务门户，确认当前商户。
3. 点击扩展图标，选择“交易明细导出”或“已上传明细导出”。
4. 在导出页面查看进度，可暂停、继续或停止。完成后在 Chrome 下载记录中查看文件。

## 注意

- 运行期间保留门户和导出页面；后台页面进度可能延迟，切回前台后恢复。
- 每次开始都会从 1 月重新申请；暂停后继续则沿用本轮进度。
- 已上传明细目前仅支持 2026 年。修改源码后需重新加载扩展。
- 失败或停止后，已提交任务仍保留，可在网站“下载暂存列表”手动下载，无需重新申请。

## 开发验证

```sh
node check.cjs
git diff --check
```
