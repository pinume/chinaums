# 银联商务助手

Chrome Manifest V3 扩展，沿用银联商务网站当前登录会话，按当前商户申请并下载年初至本月的报表。使用原生 JavaScript，无第三方依赖，无构建步骤。

## 使用

1. 在 Chrome 扩展管理页开启开发者模式，通过“加载未打包的扩展程序”选择本项目目录。
2. 打开并登录银联商务门户，在网站上确认当前商户。
3. 在该网站标签页点击扩展图标，选择“对账明细”或“以旧换新2026”。点击图标会授予 `activeTab` 临时访问权限。
4. 在新开的导出页面查看进度，使用“暂停”“继续”“停止”控制本轮流程。

流程结束后，顶部持续显示结果卡片，并更新标签页标题：绿色表示完成，红色表示失败，橙色表示用户停止。卡片显示 Chrome 已确认的下载数量；失败时同时显示具体原因，全部无数据时明确说明没有提交导出申请。

修改源码后，在 Chrome 扩展管理页重新加载扩展。以旧换新当前仅适配网站的 2026 页面；对账明细按当年生成月份范围，本月截止运行当天。

运行期间保留网站和导出页面。关闭导出页会中断流程；实测中导出页在后台时检查进度可能延迟，切回前台后恢复。

每次点击“开始”都会创建新一轮运行，从 1 月重新申请。上一轮记录会归档，已提交的服务器任务会保留；它与当前页面的“暂停／继续”不同，不是断点续传。

流程停止后，可刷新报表页，选择有数据的日期查询，再打开“下载暂存列表”手动下载已提交任务。此操作只恢复下载入口，不需要再次申请导出。

## 运行流程

- 先核对登录会话，再逐月通过网站业务接口查询并确认唯一商户身份；不选择或切换商户。
- 对账明细通过 `qryAccountCheck` 完整读取分页；以旧换新通过 `queryList` 完整读取分页。查询明确返回无数据时跳过。
- 每次申请前读取服务器暂存任务，并在提交前再次复核当前查询身份。提交成功后按新增 task ID 和文件名确认唯一归属。
- 只有明确的导出申请限流才自动重试，等待依次为 30、60、120 秒，之后最多等待 120 秒；申请成功后重置。申请结果未知时先核对，无法证明归属就停止，不重复申请。
- 所有月份提交后，通过暂存任务接口按本轮精确 task ID 约每 10 秒读取生成状态，不再打开或扫描下载暂存列表。等待期间每秒检查暂停／停止；当前等待上限为本轮开始后的 6 天。
- 全部任务 ready 后按精确 task ID 直接触发下载。Chrome 确认一份完成后才请求下一份，不会下载历史任务，也不会在完成状态不明时自动重复请求。
- 下载中断、文件被删除、完成状态无法确认、任务身份不一致或业务接口结构异常时停止，保留已提交任务供核对。

## 模块职责

| 文件 | 职责 |
|---|---|
| `manifest.json`、`popup.html`、`popup.js` | 扩展权限、网站状态、两类报表启动入口 |
| `site-config.js`、`auth.js`、`content.js` | 网站路由、登录判定、当前商户与导航的只读扫描 |
| `export.html`、`export-runner.js` | 页面与 iframe 定位、状态保存与归档、控制按钮、Chrome 下载确认 |
| `monthly-runner.js` | 两类报表共用的逐月查询、申请、限流与任务绑定流程 |
| `download-runner.js` | 两类报表共用的任务 API 生成等待、精确 task ID 直接下载和 Chrome 完成确认 |
| `account-detail.js`、`trade-audit.js` | 两类报表各自的查询/提交/任务 API、商户门禁、直接下载，以及启动时遗留弹窗清理 |
| `styles.css` | 扩展弹窗与导出页面样式 |

## 验证

使用系统已有 Node.js 运行：

```sh
node check.cjs
node export-runner.test.cjs STOPPED
node export-runner.test.cjs STOPPED trade-audit
git diff --check
```

`check.cjs` 检查 JavaScript 语法并运行现有回归，覆盖月份与日期、查询 API 完整分页与重复页、商户一致性、提交前数据漂移、申请未知结果、限流、任务生成等待、停止信号、直接下载、下载完成与中断以及重复文件。分页或任务身份无法完整证明时不得提交或下载。

两个 `STOPPED` 场景加载完整导出入口和月度运行器，用模拟 Chrome 接口在提交前触发停止按钮，确认保存为“用户停止”且不发起导出。

网站 E2E 应同时核对暂存任务、Chrome 下载记录和 XLSX 内容：数据行数与查询数量一致，清算／交易日期属于请求月份。仅看到“点击下载”或出现文件名不代表下载完成。

网站原生操作验收可用于确认页面结构和服务器行为；完整插件的 E2E 还需通过扩展入口验证，回归检查不能替代这一项验收。
